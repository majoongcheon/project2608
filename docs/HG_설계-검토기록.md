## 고치지 않고 남긴 것

| 항목 | 이유 |
|---|---|
| `pyproject.toml` 의 `[project.scripts]` 진입점 | 벤더링(`pip --target`) 방식이라 실제로 설치되지 않아 동작하지 않는다. `python -m cb_burden` 으로 쓰면 되고, 나중에 설치 방식을 바꿀 때를 위해 남긴다 |
| `models/v1.1.0`·`v1.2.0` 정리 | 실험 이력으로 가치가 있다. 새 구조에서 `models/runs/` 와 릴리스가 갈리므로 오해가 자연히 줄어든다 |
| DB 의 14문항 문항 집합(`qs-v1.1.0`) 잔재 | 서비스가 참조하지 않는다. 지우는 것은 팀 판단 |
| 추론 서비스 프로세스 관리(자동 재시작) | 지금 팀은 백엔드도 수동으로 띄운다. 이번 범위에서 자동화까지 하면 검증할 것이 늘어난다 |
