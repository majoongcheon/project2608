## 1. 개요

2024 발달장애인 일과 삶 실태조사 데이터를 바탕으로 돌봄부담 연관성이 높은 **핵심 30개
문항**을 추출해 **정량 진단(1~5단계)** 을 제공하고, **위치 기반(지도) 복지서비스 신청처
및 연락처 안내**를 원스톱으로 제공하는 서비스를 개발한다.

### 미션

- 기존의 과도한 설문 항목을 30개 핵심 문항으로 경량화하여 보호자의 설문 피로도를 최소화한다.
- 정량 진단 결과와 연동된 지역별 복지서비스 위치 및 연락처를 지도 기반으로 직관적으로 안내한다.

---

## 2. 문제 영역

**첫째, 접근 경로가 없다.** 발달장애인 보호자가 접속했을 때 직관적으로 선택할 수 있는
메뉴(① 부담감 진단용 설문조사, ② 지역별 복지서비스 신청 위치·연락처 지도 표시)가
부재하여 서비스 접근성이 저해된다.

**둘째, 설문이 무겁고 안내가 흩어져 있다.** 기존 설문조사는 문항 수가 많아 보호자의
피로도가 높고, 진단 후 복지서비스 신청처 및 연락처 안내가 파편화되어 있어 체감 복지
접근성이 떨어진다.

## 4. 설계 인공물

**2대 메뉴 선택형 보호자 전용 웹/앱 서비스**를 설계한다.

### ① 부담감 진단용 설문조사

학습 데이터 기반 연관성 높은 **30개 선택 문항**으로 구성된 **1~5단계 정량 진단 모듈**.

### ② 복지서비스 지도 안내

사용자 위치 기반 복지서비스 **신청처 위치 표시(지도 API)** 및 **기관별 연락처 제공 모듈**.

---

## 5. 설계 요구사항

1. **문항 경량화 및 진단 정확도 유지**
   기존 설문 데이터 학습을 통해 돌봄부담 예측 기여도가 가장 높은 상위 30개 문항을
   선별하고, 분류 성능(F1-Score)을 최적화한다.

2. **사용자 친화적 UI/UX**
   접속 시 보호자가 2가지 핵심 메뉴(30문항 진단 / 지도 및 연락처 안내) 중 하나를
   직관적으로 선택·이용할 수 있는 간결한 워크플로우를 구현한다.

3. **위치·연락처 정보의 실시간성 및 시각화**
   카카오/네이버 지도 API 연동을 통해 신청 위치 핀포인트 표시 및 즉시 전화 연결
   기능을 제공한다.

---

## 6. 설계 원리

**데이터 경량화 및 효율성** — 기존 설문 결과 분석을 기반으로, 연관성 높은 30개 항목
응답만으로 돌봄부담 수준을 신속·정확하게 정량화한다.

**Actionable Spatial Guidance** — 진단에 그치지 않고, 보호자가 실제 거주 지역에서
이용 가능한 복지서비스 신청 위치와 연락처를 지도로 연계하여 행동 실행력을 높인다.

## 7. 비즈니스 모델 (DDBM)

### 가치제안

- **빠르고 정확한 30문항 경량 진단** — 부담스러운 정밀 설문 대신 30개 핵심 질문만으로
  1~5단계 돌봄부담을 정량 진단한다.
- **직관적인 지도 기반 서비스 연계** — 진단 후 내 주변 복지 서비스 신청처의 위치와
  연락처를 지도로 한눈에 확인할 수 있다.

### 핵심 활동

1. **설문 항목 최적화** — 기존 실태조사 데이터 분석을 통해 돌봄부담 단계 예측
   기여도(SHAP 등)가 높은 상위 30개 핵심 문항 추출 및 전처리
2. **ML 진단 모델링** — 30개 문항 입력 기반 1~5단계 돌봄부담 다중 분류 모델 구축 및 최적화
3. **지도 및 위치 기반 서비스 개발** — 사용자 지역 기반 복지기관·접수처 위치 지도 표시
   및 기관별 연락처·신청 안내 모듈 구현

### 핵심 파트너

| 파트너 | 역할 |
|---|---|
| 한국장애인고용공단 | 실태조사 데이터 활용 및 항목 간 상관관계 분석 검증 |
| 지도/위치 데이터 API 제공사 | 카카오맵·네이버 지도 API 연동 및 지역별 복지기관 DB 구축 |
| 한국사회보장정보원 | 발달장애인지원사업 제공기관 정보 협조 |

### 핵심 이네이블러

- **Feature Selection 파이프라인** — ML 기반 주요 변수 중요도 평가를 통한 최적 30개
  설문 문항 선정
- **Map & Location API Engine** — 사용자 위치 중심의 서비스 기관 핀포인트 표시 및
  전화 걸기·길찾기 연동

### 핵심 데이터

- **학습 데이터** — 2024 발달장애인 일과 삶 실태조사 (30개 선별 변수 및 Target 1~5단계)
- **공공 복지기관 DB** — 지역별 발달장애인지원사업 제공기관의 주소, 좌표(위경도), 전화번호,
  제공 서비스 목록

### 혜택

| 대상 | 혜택 |
|---|---|
| 보호자 | 진단 참여 장벽 감소(30문항) 및 가까운 신청 위치·연락처 탐색 편의성 극대화 |
| 행정·기관 | 보호자의 서비스 접근 경로 확대를 통한 사각지대 발굴 및 복지 서비스 이용률 증가 |

### 비용

- 30개 핵심 문항 추출 및 모델 재학습 엔지니어링 공수
- 지도 API 연동 및 지역별 복지기관 위치·연락처 데이터베이스 구축·검증 비용

### 수익 (기대 효과)

- **복지 자원 최적화** — 고부담 가구 집중 지원을 통한 중복·선심성 예산 절감 효과
- **맞춤형 서비스 연계율 제고** — 정보 부족으로 인한 복지 서비스 미신청 비율 감소 및
  체감 만족도 향상

## 8. 개발 방법

1. **문항 축소 및 모델링**
   2024 실태조사 데이터 분석을 통한 핵심 30개 변수 추출 및 1~5단계 돌봄부담
   다중 분류 모델 학습·검증

2. **지도 API 및 복지기관 DB 구축**
   지역별 복지관 및 지원센터 위치 좌표, 전화번호 DB 구축 및 지도 API 연동 개발

3. **메인 인터페이스 구현**
   접속 시 2대 기능(설문조사 / 위치·연락처 지도)을 선택할 수 있는 랜딩 및 메뉴 UI 개발

## 9. 평가 방법

1. **모델 예측 성능 검증**
   30개 축소 문항 모델과 전체 문항 모델 간의 분류 정확도(Accuracy, F1-Score) 비교 및
   손실 최소화 검증

2. **지도 데이터 및 연락처 정확도 검증**
   지역별 복지기관 매핑 정확도 및 전화번호 데이터 유효성 샘플링 점검

3. **보호자 사용성 평가**
   실제 보호자 대상 30문항 소요 시간, UI 직관성 및 지도 기반 연락처 탐색 편의성 검증

## 11. 예상 장벽과 부정적 영향

### 핵심 장벽

- **문항 축소에 따른 예측 정확도 유지** — 30개 문항만으로 기존 전체 설문 대비 유사한
  수준의 진단 정확도 확보가 필요하다.
- **위치 DB 현행화** — 지자체 및 센터별 연락처·위치 정보의 비표준화 및 지속적인 데이터
  최신화 공수가 든다.

### 부정적 영향

- **문항 축소로 인한 정보 손실** — 일부 특이 케이스 가구의 돌봄 특성이 30개 문항에
  반영되지 못해 오분류될 가능성이 있다.

## 12. 기대 기여

**학술·기술적 기여** — 복잡한 설문 데이터를 머신러닝 변수 중요도 분석으로 30개 문항까지
축소하면서도 진단 성능을 유지하는 **경량화 프레임워크**를 제시한다.

**사회·정책적 기여** — 보호자의 설문 피로도를 대폭 낮추고, 내 주변 서비스 신청처와
연락처를 즉시 안내함으로써 **사각지대 보호자의 복지 접근 장벽을 실질적으로 해소**한다.
