## 0. 직접 고칠 수 있게 만든 방법

요청하신 대로 **그림과 글을 완전히 분리**했습니다.

| 요소 | 형태 | 고치는 법 |
|---|---|---|
| 제목 · 본문 · 캡션 | **편집 가능한 텍스트 상자** (문단 단위로 분리) | 클릭해서 바로 수정 |
| 표 | **pptx 표 개체** | 셀 단위로 수정 · 행 추가 삭제 가능 |
| 차트 · 도식 | **별도 그림 개체** | 지우거나 갈아 끼워도 글이 안 깨짐 |

**그림 안에 글자가 구워져 있지 않습니다.** 이전 자료는 제목·해설·화살표 주석이 차트와 한
이미지로 합쳐져 있어 글자만 고칠 수 없었는데, 이번에는 축 이름 · 눈금 · 범례 · 값 라벨만
이미지에 남겼습니다.

**그림을 다시 뽑고 싶으면**

```bash
PYTHONPATH=ml/.pylibs python3 ml/JSG-visual-slides.py       # V01~V17 차트
PYTHONPATH=ml/.pylibs python3 ml/JSG-deck-extra-charts.py   # V18 시스템 구성 · V19 군집
PYTHONPATH=ml/.pylibs python3 ml/JSG-pipeline-diagram.py    # 전체 파이프라인
PYTHONPATH=ml/.pylibs python3 ml/JSG-build-deck.py          # 발표자료 전체 재생성
```

원본 PNG 는 `docs/assets/발표용/` 에 있습니다. 색이나 축 범위를 바꾸려면 각 스크립트의
팔레트 상수만 고치면 됩니다.

## 2. 군집화 표현을 이렇게 정리했습니다

이전 자료는 *"데이터에 군집 구조가 없다"* 고 말하고 있었습니다. **그 표현은 틀렸습니다.**
대신 두 장으로 나눠 정직하게 적었습니다.

### 슬라이드 11 — 구조는 있다

| | 값 |
|---|---|
| 실측 실루엣 | **0.1179** |
| 널 베이스라인 평균 (20회) | 0.0043 |
| p 값 | **0.000** — 널 대비 **27배** |
| 최적 k | **3** · 리프트 0.54 → 1.03 → 1.45 로 **단조 증가** |

앞선 실험이 같은 0.12 를 보고 "구조 없음"이라 한 것은 **0.25 라는 기준이 저차원 연속
데이터용 관례표**이기 때문입니다. **차이는 방법이 아니라 비교 대상을 만든 것**입니다.

### 슬라이드 12 — 그래도 천장은 그대로다

군집만으로 판정했을 때의 정확도를 이번에 직접 계산했습니다
(`SJH-군집화-결과.json` 에는 정확도 지표가 없었습니다).

| 판정 방법 | 입력 | 고부담 여부 정확도 | 고부담 재현율 | 5구간 정확도 |
|---|---|---|---|---|
| 군집만으로 (다수결 배정) | 190변수 (원본 507컬럼) | **68.97 %** | 0.8127 | **44.37 %** |
| 배포본 7문항 로지스틱 | 7문항 | 69.4 % | 0.7844 | 46.3 % |

**반드시 함께 말할 것 두 가지**

1. **군집 쪽은 재대입(resubstitution) 값입니다.** 군집도 배정도 같은 2,398건을 보고
   정했고 교차검증이 없습니다. **군집에 유리하게 기울어진 비교인데도 배포본과 같은 자리**입니다.
2. **대체재가 아닙니다.** 새 응답자를 군집에 배정하려면 507컬럼 설문에서 뽑은 190변수가
   필요합니다. 서비스는 7문항을 묻습니다.

> **발표 문장** — *"구조는 있습니다. 다만 돌봄부담을 5구간으로 가를 만큼은 아닙니다."*
> "없다"보다 **"찾아봤더니 있었고, 그런데도 천장은 그대로였다"** 가 근거로 더 강합니다.

**보완 사항으로 남긴 것** — 폴드마다 군집을 다시 만들어 재는 **교차검증 정확도는 아직
측정하지 않았습니다.** 슬라이드 25(한계)에 그대로 적어 두었습니다.
