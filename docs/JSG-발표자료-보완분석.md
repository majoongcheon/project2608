  두 사람을 다른 색으로 칠하고 `aria-hidden` 처리
- **노을 4색** — 테라코타 `#b5563a` · 살구 `#d2703f` · 복숭아 `#f0b678` · 자두 `#7d4a5f`
- **색을 바꾸기 전에 수치로 검증했다** ← 이게 발표 포인트다
  - 살구 면 대비 3.30:1 (WCAG 1.4.11 통과) · 글자용은 5.15:1 (AA)
  - 복숭아 1.74:1 → **글자로는 안 쓴다**
  - 색각이상 분리도 ΔE 10.5~26.2 (목표 8 초과)
  - 부담 5단계 명도 L 이 0.070 → 0.775 **단조 증가** → 색을 못 봐도 순서가 읽힌다
  - 이용 흐름 1·2·3 명도 0.62 → 0.168 → 0.096 **단조 감소**
- **첫 화면의 단 하나의 숫자** — "3,000가구 중 1,629가구(54.3%). 힘든 것은 당신만의 일이 아닙니다."

### A6. 팀 · 방법론 · 계획 대비 변경

발표에 **팀 소개도, 방법론도, 일정도 없다.** 그리고 더 중요한 것 —

> **계획서는 "핵심 30개 문항" 이었고, 실제 결과는 7문항이다.**

슬라이드 7이 7문항의 근거를 잘 설명하지만, **"계획은 30이었다"** 는 말이 없다.
계획서를 든 심사자에게는 축소가 아니라 **성과**로 읽혀야 한다.

| 계획 (`JSG-프로젝트-계획서.md`) | 실제 | 한 줄 설명 |
|---|---|---|
| 핵심 **30문항** | **7문항** | 문항 수를 먼저 정하지 않고 성능 손실 허용치를 정해 결과로 얻었다 |
| SHAP 등 변수 중요도 | **후진 제거** | 단독 설명력 순위는 변수 간 중복을 못 걸러낸다 (슬라이드 7·10) |
| 카카오/네이버 지도 API | **Leaflet + OSM** | 키가 필요 없어 배포 장벽이 없다 |
| 1~5단계 정량 진단 | 유지 + **판정 불가** | 5구간을 그대로 두되 못 맞히는 구간을 판정하지 않는 길을 추가 |

**DSR(Design Science Research)** 프레이밍도 넣을 만하다 — 문제 영역 → 설계 인공물 →
평가 방법 → 기여. 지금 18장이 사실상 이 순서인데 이름표만 없다.

**팀 구성** (계획서 §14):

## 3. B급 — 있으면 발표가 단단해지는 것

### B1. 슬라이드 6 을 실제 규모로 — 3종 → 11종 + 앙상블 9구성

지금 슬라이드 6은 **로지스틱 / 랜덤포레스트 / 엑스트라트리 3종**만 보여준다.
실제로 팀이 돌린 것은 훨씬 크다.

| 실험 | 규모 | 결과 | 문서 |
|---|---|---|---|
| 신지현 벤치마크 | 단일 7종 + 앙상블 4종 = **11구성** × 2문항셋 | 7문항·38변수 **양쪽 다 로지스틱 1등** | `SJH-데이터준비와-모델선정.md` §7·§8 |
| 최호준 재측정 | 단일 5종 + 앙상블 4종, **5회 반복 CV + 부트스트랩 2,000회** | **이긴 구성 0개** | `CHJ-앙상블비교-결과.md` |
| 최호준 인코딩 | 인코딩 6종 | `scale+collapse` 만 이겼다 (§4 참조) | `CHJ-인코딩비교-결과.md` |

**최호준 실험의 핵심 한 줄** — 기존 벤치마크는 클래스 가중치를 OOF 전체에서 고르고
같은 OOF 에서 채점해 낙관 편향이 있었다. 편향을 걷어내고 **두 종류의 신뢰구간**
(반복 CV = 분할 잡음 / 행 부트스트랩 = 표본 잡음)을 계산했다.

> **쫓던 차이(0.006~0.014)가 기준선 자신의 흔들림(표준편차 0.0049)과 같은 크기였다.**

발표 문장은 최호준이 이미 써 두었다 — *"앙상블을 4가지 방식으로 검토했고, 차이가 잡음인지
가리려고 두 종류의 신뢰구간까지 계산했다. 이긴 구성이 없어서 단일 모델을 유지했다."*
**성능을 못 올린 실험이 아니라, 올릴 수 없다는 것을 근거로 보인 실험이다.**

### B2. 실험 6개가 전부 기각됐다 — 슬라이드 5·17 의 진짜 근거

슬라이드 5는 "정확도 48%는 모델 탓이 아니다" 를 **군집화 하나**로만 변호한다.

| # | 실험 | 결과 |
|---|---|---|
| 1 | 문항 7 → 14개 | 폐기 — F1 +0.0004, 판정 불가 2.49% → 4.20% (1.7배) |

## 7. 09-03 시현 대본에 반드시 들어갈 것

1. **아무 값이나 넣지 말 것.** 무작위 응답은 63%가 판정 불가로 빠진다. 고장이 아니다.
   - 고부담 시연 입력 `[2, 1, 1, 1, 없음, 2, 1]`
   - 중간부담 시연 입력 `[4, 4, 5, 1, 없음, 3, 1]`
2. **판정 불가도 한 번 보여줄 것.** 기관 안내가 그대로 나가는 것이 이 서비스의 설계다.
3. 기동 순서 — **추론 서비스 먼저, 백엔드 나중.** 백엔드가 기동 때 문항 집합을 대조한다.
4. health 는 `/api/v1/health` (SPA fallback 때문에 다른 경로는 200 이 나온다).
5. `consentTraining` 없이 호출하면 DB 에 행이 생기지 않는다 — 시연이 데이터를 더럽히지 않는다.
