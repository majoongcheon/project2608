### 한 줄 덧붙이면 좋은 것

표 아래에 —

> **화면 문구는 원 조사표를 보호자가 답할 수 있는 말로 옮긴 것입니다. 선택지 값과 순서는 원 척도를 그대로 씁니다.**

원 설문지와 다른 것을 **먼저 밝히는 편**이, 심사에서 "원문과 다른데요" 를 듣는 것보다 낫습니다.

## 3. 순서에 대한 참고

발표자료 S15 는 **단독 설명력 순**(G6 → F1 → F5 → G8 → I4 → A1 → E4)이고,
서비스 화면은 **문항 번호 순**(G8 → F5 → G6 → I4 → E4 → A1 → F1)입니다.

둘이 다른 것은 문제가 아닙니다. 다만 시연에서 화면을 보여줄 때 **"슬라이드는 설명력 순,
화면은 응답 순서"** 라고 한마디 해 두면 혼선이 없습니다.
