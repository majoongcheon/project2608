## 1. 지금 바로 — S19 숫자 두 개 ★ (2분)

**슬라이드 19 "할 수 있는 것 — 고부담 여부" 표에 다른 실험의 값이 들어가 있다.**

| 지금 | 맞는 값 | |
|---|---|---|
| 고부담 재현율 `0.7730` | `0.7730` | 맞음 |
| 고부담 정밀도 `0.695` | **`0.698`** | 고칠 것 |
| 고부담 여부 정확도 **`68.97 %`** | **`69.6 %`** | **고칠 것 ★** |

### 왜 틀렸나

`68.97 %` 는 **슬라이드 12 의 군집 실험 값**이다. 어제 *"이진 정확도 → 고부담 여부 정확도로
이름을 통일하자"* 고 권했는데, **이름을 맞추면서 값까지 S12 에서 가져온 것**으로 보인다.
값의 출처를 함께 적지 않은 내 잘못이다.

**세 숫자가 서로 다른 것이다.**

```
68.97 %   군집만으로 판정 (train · 교차검증 없는 재대입)   ← S12
69.4  %   배포본 7문항 (train 5-fold)                    ← S12
69.6  %   배포본 7문항 (test 602건)                      ← S19 가 써야 할 값
```

### 근거 — test 602건 혼동행렬

```
             예측 고부담   예측 아님
실제 고부담      252         74
실제 아님        109        167

재현율  252/326 = 0.7730
정밀도  252/361 = 0.6981
정확도  419/602 = 0.6960
```

`docs/HG-모델-성능-리포트.md` §test(602건). 제출용 `model_card.md` 와도 같은 실행이다.

> **심사에서 나올 수 있다.** S12 에 68.97 이 있고 S19 에도 68.97 이 있으면
> *"군집이랑 모델이 정확도가 똑같네요?"* 라는 질문이 바로 나온다.

## 2. 5분 안에 — 문장 두 곳 (5분)

### 2-1. S11 에 같은 말이 두 번 나온다

어투를 바꾼 문장을 넣으면서 **원래 문장이 남아 있다.**

```
판정은 널 베이스라인으로
열별 셔플로 "구조가 확실히 없는 데이터"를 20번 만들어 같은 파이프라인을 태웠습니다.   ← 옛 문장

관계를 일부러 지운 가짜 데이터를 스무 번 만들어 똑같이 나눠 봤습니다.
실제 데이터 쪽이 확실히 더 뚜렷하게 나뉘었습니다                                    ← 새 문장
```

**위 두 줄(옛 문장)을 지우면 된다.** 제목 "판정은 널 베이스라인으로" 도 함께 지우거나
**"비교 대상을 만들어 봤습니다"** 로 바꾸는 편이 낫다.

### 2-2. S11 아래 캡션이 본문에 없는 숫자를 가리킨다

캡션에 *"앞선 실험은 같은 **0.12** 를 보고 …"* 가 남아 있는데,
본문에서 실루엣 수치를 뺐기 때문에 **0.12 가 어디서 온 숫자인지 슬라이드에 없다.**

→ 캡션을 이렇게 고친다.

> **앞선 실험은 같은 결과를 보고 "구조 없음"이라 했습니다. 판정 기준이 이 데이터에
> 맞지 않았고, 차이는 방법이 아니라 비교 대상을 만든 것입니다.**

## 3. 여유가 있으면 (10분)

### 3-1. S23 합계 행 — 대상 칸이 비어 있고 402곳 설명이 없다

```
| 합계 (중복 기관 제외) |      | 875 | 221 |
                        ↑ 비어 있음
```

대상 칸에 **`—`** 를 넣고, 표 아래에 한 줄을 더한다.

> **402곳은 두 가지를 함께 운영합니다. 연락처는 835곳(95.4%)에 있습니다.**

이 한 줄이 없으면 *"724 + 553 = 1,277 아닌가요"* 를 다시 듣게 된다.

### 3-2. 표 안에서만 말투가 다르다

표는 `~다` 체인데 두 칸만 `~습니다` 다.

| 슬라이드 | 지금 | 이렇게 |
|---|---|---|
| S6 ⑥ 변환 | 빈칸을 '없음'이라는 하나의 답으로 두고, 선택지마다 칸을 **나눴습니다** | 빈칸을 '없음'이라는 답으로 두고 선택지마다 칸을 **나눈다** |
| S9 잘못 | 검증용으로 남겨 둔 답을 보고 설정을 고른 다음, 같은 답으로 **채점했습니다** | 검증용으로 남겨 둔 답으로 설정을 고르고 **같은 답으로 채점** |

### 3-3. S25 대응 문장이 한계와 안 맞는다

```
한계   설명변수가 5구간을 가를 정보를 못 담음
대응   여섯 번 다 해봤지만 의미 있는 차이가 나온 것은 하나도 없었습니다
```

"정보를 못 담는다"에 대한 대응이 "실험했지만 차이가 없었다"라 **말이 이어지지 않는다.**
어투를 바꾸면서 *"실험 여섯 개로 **확인**"* 의 '확인'이 빠진 탓이다.

→ **"모델을 여섯 가지로 바꿔 봤지만 나아지지 않아, 데이터의 성질임을 확인했습니다"**

### 3-4. S15 · 7번 문항이 화면과 조금 다르다

| | |
|---|---|
| 화면 | (당사자가 일을 그만둔 적이 있다면) 마지막 일자리를 그만둔 가장 큰 이유는 **무엇인가요?** |
| 슬라이드 | … 가장 큰 이유는**?** |

2번(F1)도 화면은 "이해하**고 있**나요?" 다. **둘 다 뜻이 같아 안 고쳐도 된다.**
시연에서 화면을 띄우고 슬라이드와 나란히 볼 일이 있으면 그때만 맞추면 된다.

## 5. Q&A 대비 — 손에 쥐고 갈 숫자

슬라이드에서 덜어낸 값들이다. **물어보면 그때 답한다.**

| 질문 | 답 |
|---|---|
| 기관이 몇 곳입니까 | **875곳.** 724와 553을 더하면 두 유형을 함께 하는 402곳을 두 번 셉니다 |
| 군집 실루엣이 얼마입니까 | 0.1179. 관계를 지운 가짜 데이터가 0.0043이라 **널 대비 27배**입니다 |
| 판정 불가 임계값은 어떻게 정했습니까 | 확신도 0.32392 · 희소성 −2.43427. **격자 탐색**으로 찾았습니다 |
| 실험이 우연이 아니라는 근거는 | 폴드 다섯이라 \|t\| ≥ 2.776 을 넘겨야 하는데 **여섯 실험 모두 못 넘겼습니다** |
| 접근성은 고려했습니까 | 부담 5단계를 **명도 단조 증가**로 두어 색을 못 봐도 순서가 읽힙니다. 대비도 WCAG 기준으로 확인했습니다 |
| 왜 인과를 말하지 않습니까 | **도와줄 사람이 없는 집이 오히려 부담이 적게 나옵니다**(2.517 vs 2.471). 없어서 편한 게 아니라 감당이 안 되니 사람을 부른 겁니다. 관계와 원인은 다릅니다 |
| 7문항 중 가구주 문항은 왜 중요합니까 | **가구주가 자녀인 집이 29곳** 있었고 그 청년들의 취업률은 3.4%, 부담은 가장 높았습니다. 부모가 나이 들어 자녀가 부양을 떠안은 집들입니다 |
