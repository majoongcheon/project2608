## 가장 중대한 발견 — 시드가 달랐다

계획서에 `SEED = 42` 라고 적어 두었는데 **원본 `ml/train.py` 의 시드는 `20260901`** 이었다.
그대로 구현했다면 같은 데이터로도 **다른 모델이 나왔을 것**이고, 이관 합격 기준
("현재 배포본과 1e-9 이내 일치")이 깨졌을 것이다.

Task A7 에서 원본을 읽다가 발견해 `config.py` 와 테스트를 고쳤다.
**계획서를 그대로 믿지 않고 원본을 읽은 것이 잡아냈다.**

```python
# ★ 원본 ml/train.py 와 같아야 한다. 다르면 다른 모델이 나온다.
SEED = 20260901
```

`test_config.py` 에 회귀 테스트를 넣어 다시 어긋나지 않게 했다.
