# 머신러닝 방법론: 발달장애인 보호자 돌봄부담 진단 설문을 중심으로

## 1. 개요

발달장애인 보호자 돌봄부담 진단 설문 데이터를 분석할 때 머신러닝과 데이터 분석의 목적은 단순히 **돌봄부담 수준을 예측하는 것**에만 있지 않습니다.

연구 목적에 따라 크게 다음 네 가지로 구분할 수 있습니다.

| 구분 | 핵심 질문 | 발달장애 진단 설문에서의 목적 |
|---|---|---|
| **Summary** | 무슨 현상이 나타나는가? | 보호자와 돌봄부담 현황 요약 |
| **Relation Description** | 어떤 요인들이 관련되는가? | 부담과 관련된 요인 탐색 |
| **Causal Explanation** | 왜 부담이 발생하는가? | 돌봄부담의 인과적 원인 설명 |
| **Prediction** | 새로운 대상은 어떤 결과를 보일까? | 설문 응답으로 부담 수준 예측 |

---

# 2. Summary — 대상 현상을 요약하는 것

## 핵심 질문

> **발달장애인 보호자 돌봄부담 진단 설문에서 어떤 현상이 나타나는가?**

Summary는 설문 데이터를 이해하기 쉽게 요약하는 단계입니다.

예를 들어 I13 문항을 통해 보호자의 돌봄부담을 다음과 같은 5단계로 분류한다고 가정할 수 있습니다.

- 1단계: 최고 부담
- 2단계: 높은 부담
- 3단계: 중간 부담
- 4단계: 낮은 부담
- 5단계: 부담 없음

### 분석 예시

- 전체 응답자 중 최고 부담군의 비율은 얼마인가?
- 연령대별 돌봄부담 분포는 어떠한가?
- 장애 특성별 부담 수준은 어떻게 다른가?
- 보호자의 경제적·정서적 부담은 어떤 항목에서 높은가?

### 활용 방법

- 빈도 분석
- 비율 분석
- 평균 및 중앙값
- 표준편차
- 막대그래프
- 히스토그램
- Box Plot

### 핵심

> **현재 설문 응답자 집단에서 어떤 특징과 분포가 나타나는가?**

를 보여주는 것이 Summary입니다.

---

# 3. Relation Description — 변수 간 관계를 기술하는 것

## 핵심 질문

> **어떤 설문 요인이 돌봄부담 수준과 관련되어 있는가?**

예를 들어 다음과 같은 관계를 탐색할 수 있습니다.

- 돌봄시간과 돌봄부담의 관계
- 보호자의 경제적 어려움과 돌봄부담의 관계
- 사회적 지원 수준과 돌봄부담의 관계
- 장애인의 행동 특성과 보호자 부담의 관계

### 분석 예시

| 요인 | 돌봄부담과의 관계 |
|---|---|
| 돌봄시간 증가 | 부담 증가 경향 |
| 사회적 지원 증가 | 부담 감소 경향 |
| 경제적 어려움 증가 | 부담 증가 경향 |
| 휴식시간 부족 | 부담 증가 경향 |

### 주요 방법

- Correlation Analysis
- Regression Analysis
- Chi-square Test
- Feature Importance
- SHAP Analysis

## 중요한 점

관계가 발견되었다고 해서 반드시 원인이라고 말할 수는 없습니다.

예를 들어:

> 사회적 지원이 적은 보호자의 돌봄부담이 높다.

는 **관계**를 보여줄 수 있지만,

> 사회적 지원 부족이 반드시 돌봄부담의 원인이다.

라고 바로 결론 내릴 수는 없습니다.

---

# 4. Causal Explanation — 돌봄부담의 원인을 설명하는 것

## 핵심 질문

> **왜 특정 보호자에게 높은 돌봄부담이 발생하는가?**

인과 설명은 단순히 변수들이 함께 변화하는지를 보는 것이 아니라, 특정 요인이 실제로 결과에 영향을 주었는지를 분석합니다.

### 예시

관찰 결과:

> 경제적 어려움이 큰 보호자일수록 돌봄부담 수준이 높다.

하지만 이것만으로 경제적 어려움이 돌봄부담의 직접적인 원인이라고 단정할 수 없습니다.

다른 요인이 동시에 영향을 미칠 수 있기 때문입니다.

예:

- 장애인의 지원 필요도
- 보호자의 건강 상태
- 가족 구성
- 이용 가능한 사회서비스

이러한 요인을 **교란 변수(Confounding Variable)**라고 합니다.

### 주요 방법

- Longitudinal Study
- Randomized Controlled Trial
- Propensity Score Matching
- Difference-in-Differences
- Structural Causal Model
- DAG

### 핵심

> **관련이 있다(Relation)** 와 **원인이다(Causation)** 는 서로 다릅니다.

---

# 5. Prediction — 새로운 보호자의 돌봄부담 수준 예측

## 핵심 질문

> **새로운 보호자의 설문 응답을 입력했을 때 돌봄부담 수준을 예측할 수 있는가?**

이것이 현재 시스템에서 머신러닝을 적용할 수 있는 핵심 영역입니다.

## 입력 변수(X)의 예

- 보호자 특성
- 돌봄시간
- 장애인의 지원 필요도
- 경제적 상황
- 가족 및 사회적 지원
- 휴식과 여가 수준
- 정서적 부담 관련 설문 응답

## 목표 변수(Y)

예를 들어 I13의 돌봄부담 5단계를 목표값으로 사용할 수 있습니다.

```text
설문 응답 데이터
       ↓
데이터 전처리
       ↓
특징 변수 선택
       ↓
머신러닝 모델
       ↓
돌봄부담 5단계 예측
```

### 가능한 모델

- Random Forest
- XGBoost
- Support Vector Machine
- Neural Network

---

# 6. 매우 중요한 문제: Data Leakage

돌봄부담 예측 모델에서는 **목표값을 직접적으로 포함하거나 사실상 답을 알려주는 변수**를 입력값으로 사용하면 안 됩니다.

예를 들어 I13이 돌봄부담 수준의 목표 변수(Target)라면, I13의 결과를 직접적으로 구성하거나 거의 동일한 의미를 가진 문항을 그대로 입력 변수로 사용하면 모델 성능이 인위적으로 높아질 수 있습니다.

이러한 문제를 **Data Leakage(데이터 누수)**라고 합니다.

따라서 데이터 준비 단계에서는:

- 목표 변수 정의
- Leakage 변수 제거
- 후보 변수 검토
- 중복 정보 제거

가 중요합니다.

# 9. Clustering과 Profiling의 역할

발달장애인 보호자 설문 데이터에서는 예측 이전에 **유사한 특성을 가진 보호자 집단을 탐색**할 수도 있습니다.

예를 들어 다음과 같은 유형이 발견될 수 있습니다.

### 유형 A: 경제적 부담 중심형

- 경제적 어려움 높음
- 돌봄시간 높음
- 사회적 지원 부족

### 유형 B: 정서적 부담 중심형

- 정서적 스트레스 높음
- 휴식 부족
- 사회적 관계 감소

### 유형 C: 상대적 안정형

- 사회적 지원 충분
- 부담 수준 낮음
- 휴식과 돌봄 자원 확보

이러한 분석은 **Clustering**과 **Profiling**을 통해 수행할 수 있습니다.

중요한 점은 클러스터링은 정답을 예측하는 방법이 아니라,

> **설문 응답자 안에 어떤 유형의 집단이 존재하는지 발견하는 방법**

이라는 것입니다.

# 10. 현재 시스템에 적합한 연구 구조

발달장애인 보호자 돌봄부담 진단 설문 시스템은 다음과 같이 정리할 수 있습니다.

> **발달장애인 보호자의 설문 응답 데이터를 기반으로 돌봄부담의 현황과 관련 요인을 분석하고, 응답자 유형을 탐색한 후 머신러닝을 이용하여 새로운 보호자의 돌봄부담 수준을 예측하는 시스템**

이를 그림으로 표현하면 다음과 같습니다.

```text
설문 데이터 수집
      ↓
Summary
현재 보호자 집단의 현황 파악
      ↓
Relation Analysis
돌봄부담 관련 요인 탐색
      ↓
Feature Selection
중요 변수 선택 및 Leakage 제거
      ↓
Clustering / Profiling
보호자 유형 탐색
      ↓
Machine Learning
예측 모델 구축
      ↓
Prediction
새로운 보호자의 돌봄부담 수준 예측
```

# 11. 핵심 결론

발달장애인 보호자 돌봄부담 진단 설문에서 머신러닝과 데이터 분석은 다음 네 가지 목적을 가질 수 있습니다.

1. **Summary**  
   설문 응답자와 돌봄부담의 현재 상태를 요약한다.

2. **Relation Description**  
   어떤 요인들이 돌봄부담과 관련되어 있는지 탐색한다.

3. **Causal Explanation**  
   왜 돌봄부담이 발생하는지 인과적 원인을 분석한다.

4. **Prediction**  
   새로운 보호자의 설문 응답을 이용하여 돌봄부담 수준을 예측한다.

특히 중요한 원칙은 다음과 같습니다.

> **관계가 있다고 해서 인과관계가 있는 것은 아니다.**

그리고,

> **예측을 잘한다고 해서 원인을 설명하는 것은 아니다.**

따라서 발달장애인 보호자 돌봄부담 진단 시스템에서는 먼저 분석 목적을 명확하게 정의하고, 목표 변수와 입력 변수를 분리하며, Data Leakage를 방지한 후 적절한 머신러닝 모델을 구축하는 것이 중요합니다.
