| 코드 | 원 조사표 (정답) | 우리 화면 (옛) |

### 2-2. E4 문항에 주어가 없었다

7문항 중 **E4 만 주어가 없어** 보호자가 자기 일자리로 오해할 여지가 있었다.

```

후  (당사자가 일을 그만둔 적이 있다면) 마지막 일자리를 그만둔 …
```

### 2-3. 기관 수와 서비스 수를 혼동하고 있었다

슬라이드가 `724 + 553` 을 나란히 두어 듣는 사람이 더하게 되어 있었다.

```
주간활동 724곳 · 방과후 553곳 · 둘 다 402곳
  주간활동만 322 + 방과후만 151 + 둘 다 402 = 875곳
  검산  724 + 553 - 402 = 875
```

**기관은 875곳**이고 서비스가 1,277건이다. 시군구도 217+196 이 아니라 **합집합 221곳**.
연락처는 835곳(95.4%)에 있다.

## 3. 확인해서 답을 만든 것

### 3-1. "구조가 있다면 정확도는 얼마인가"

신지현의 원본 507컬럼 군집화가 *"구조 없음"* 결론을 뒤집었는데, **정확도는 아무도 재지
않았다**(결과 JSON 에 지표 없음). 교차표에서 직접 계산했다.

| 판정 방법 | 고부담 여부 정확도 | 5구간 정확도 |
|---|---|---|
| 군집만으로 (다수결) | 68.97 % | 44.37 % |
| 배포본 7문항 로지스틱 | 69.4 % | 46.3 % |

**군집 쪽은 교차검증 없는 재대입 값이라 유리하게 기운 비교인데도 같은 자리다.**

→ 발표 문장: *"구조는 있습니다. 다만 5구간으로 가를 만큼은 아닙니다."*
"없다"보다 **"찾아봤더니 있었고, 그런데도 천장은 그대로였다"** 가 더 강하다.

## 5. 방향이 틀려 되돌린 것

발표자료 검토 **1판은 "근거를 더 넣자"** 는 방향이었다. 팀 피드백으로 틀렸음이 확인됐다.

> *"색수치 같이 분석이 필요한 내용을 억지로 집어넣으면 AI가 만들었다고 광고하는 느낌이 있다."*

**철회한 권고 3건** — S22 색 대비 수치 복원 · 용어 정의를 슬라이드에 괄호로 추가 ·
제출 산출물 파일 목록 1장.

**대신 방향을 뒤집었다** — 용어를 *설명하는* 게 아니라 *빼는* 쪽으로. 정밀한 숫자는
슬라이드에서 덜어내고 손에 쥐고 있다가 질문받을 때 답한다.

```
전  "실측 실루엣 0.1179 · 널 평균 0.0043 · p = 0.000 · 널 대비 27배"
후  "관계를 일부러 지운 가짜 데이터를 스무 번 만들어 똑같이 나눠 봤습니다.
     실제 데이터 쪽이 확실히 더 뚜렷하게 나뉘었습니다"
```

**오늘 배운 것 중 이게 제일 크다.** 발표자료는 분석 보고서가 아니다.
