### UNK-01 · 카카오 키 없이 지도 시각화

- **접수일**: 2026-09-01
- **분류**: 지도 / 화면
- **상태**: 접수
- **관련**: FR-016(지도+목록), FR-017(기관 정보), FR-018(길찾기), research.md **R-7**,
  `frontend/src/components/MapView.vue`, `frontend/.env.local`

**원문**

> \# 의료기관 지도 시각화 중심좌표는 의료기관 위치의 평균 위도, 경도 값으로 설정
>
> ```python
> pharmacy_map = folium.Map(location=[dj_map_df['위도'].mean(),
>                                    dj_map_df['경도'].mean()],
>                          zoom_start=11)
>
> # 중심좌표 확인하기
> folium.Marker(location=[dj_map_df['위도'].mean(),
>                         dj_map_df['경도'].mean()],
>               ).add_to(pharmacy_map)
>
> # 의료기관 위치에 마커 추가하기
> for idx in dj_map_df.index:
>   popup_text = str(dj_map_df['약국명'][idx])
>   popup_text += '<br>' + str(dj_map_df['주소'][idx])
>
>   # 좌표값 추출하기
>   lat = dj_map_df['위도'][idx]
>   lng = dj_map_df['경도'][idx]
>
>   # 지도 추가하기
>   folium.Marker(location=[lat, lng],
>                 icon= folium.Icon(color='blue', icon='plus-sign'),  # icon 설정
>                 popup= folium.Popup(popup_text, max_width=300)).add_to(pharmacy_map) # popup width 설정
>
> pharmacy_map
> ```
>
> 이런식으로 지도에 표시하는 방식을 참고해서 카카오키가 필요없이 지도로 시각화 하도록 구성하고 싶어.

**메모** (내가 확인한 사실 — 원문과 섞지 않는다)

- 예시의 `folium` 은 내부적으로 **Leaflet + OpenStreetMap 타일**을 쓴다. 발급 키가 없는 이유가
  여기 있다. 우리 런타임은 Vue/TS 라 folium 을 그대로 쓸 수는 없고, **Leaflet 을 직접 쓰면
  같은 결과**가 된다(키 불필요, 마커·팝업·중심좌표 모두 동일 개념).
- **이 요청은 research.md R-7 의 결정을 뒤집는다.** R-7 은 Kakao 를 채택하며 Leaflet+OSM 을
  "국내 상세 주소·건물 정보가 부족해 FR-017 품질을 못 맞춘다"는 이유로 기각했다.
  종합 시 이 판단을 다시 볼지 결정해야 한다.
- 뒤집어도 되는 근거는 있다 — 기관 좌표 1,283건이 **이미 DB 에 확보**되어 있어(결측 0건)
  지오코딩이 필요 없다. 지도의 역할이 "이미 아는 좌표에 마커를 찍는 것"뿐이라면
  OSM 타일로 충분하고, R-7 이 걱정한 주소 검색 품질은 쟁점이 되지 않는다.
- **중심좌표를 마커 평균으로 잡는 방식**은 현재 구현과 다르다. 지금은 기준 위치(내 위치 또는
  선택 지역 대표 좌표)를 중심으로 두고 `setBounds` 로 마커 전체를 담는다. 평균 좌표 방식으로
  바꿀지, 지금의 bounds 방식을 유지할지 함께 정해야 한다.
- **FR-018 길찾기는 영향이 없다.** 현재도 `map.kakao.com/link/search/` 링크를 여는 방식이라
  API 키를 쓰지 않는다. SDK 를 걷어내도 그대로 동작한다.
- 예상 변경 범위: `MapView.vue` 전면 교체, `leaflet` 의존성 추가,
  `VITE_KAKAO_MAP_KEY` 제거, `quickstart.md`·`CLAUDE.md`·`research.md R-7` 갱신.
- **확인 필요**: OSM 타일 서버는 외부 CDN 이다. 오프라인·폐쇄망 시연 계획이 있다면
  타일도 못 받으므로, 그때는 지금의 목록 폴백이 그대로 필요하다.
