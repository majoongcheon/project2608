## 0. 한 장 요약

원본 조사 파일 `data/snapshots/2024.csv`(3,000행 × **507컬럼**)로 군집화를 처음부터 다시 한다.
기존 `v_cb_tree_v1`(38변수) 기반 군집화(`notebooks/HG-실험-군집화.ipynb`)와 그 결론은 참고만
하고 근거로 삼지 않는다.

**핵심 설계 판단** — 이 데이터의 결측은 무응답이 아니라 **설문 분기(skip logic)** 때문이다.
분기 하나가 컬럼 수십 개를 동시에 비운다. 그대로 거리를 재면 *"취업 경험 없음"* 이라는 사실
하나가 E블록 52개 컬럼만큼, 즉 **52표**를 갖는다. 그래서 **분기를 게이트 변수 하나로 승격시키고
하위 문항은 해당자끼리만 비교한다.**

## 1. 왜 다시 하는가

기존 실험(`HG-실험-군집화.ipynb`)의 결론은 *"데이터에 구조가 없다 — 실루엣 0.12, ARI 0.027,
PCA 1성분 12.9%"* 였고, 이것이 `docs/SJH-데이터준비와-모델선정.md` §7-3 의 근거로 쓰이고 있다.
2026-09-02 검토에서 아래를 확인했다.

| # | 문제 | 성격 |
|---|---|---|
| 1 | 연속형 4 · 순서형 12 를 포함한 38변수를 **전부 원-핫**(326열)한 뒤 유클리드 KMeans. 혼합형 데이터에 부적절하고 순서 정보가 소멸한다 | 방법 |
| 2 | 원-핫에 **PCA**. 이진 변수의 분산은 빈도(`p(1-p)`)에 종속돼 희귀 범주가 버려지고, "열 합 = 1" 이라는 인위적 제약이 주성분으로 잡힌다 | 방법 |
| 3 | 표준화가 없어 **레벨 수가 곧 가중치**가 된다. "같은 자로 잰다"는 의도와 반대로 작동 | 방법 |
| 4 | **널 베이스라인이 없다.** 고차원 원-핫에서 실루엣 0.12 가 낮은 값인지 판단할 비교 대상이 없다 | 검증 |
| 5 | `ARI ≈ 0` 을 "데이터에 정보가 없다"로 해석. 비지도 군집이 특정 라벨을 재현하지 못하는 것은 흔한 일이며, 같은 데이터로 지도학습이 고부담 재현율 0.78 을 낸다 | 해석 |
| 6 | 교차표의 **군집 4 는 고부담 80.6%** 로 전체 54.4% 대비 1.48배인데 "무관"으로 정리됨 | 해석 |
| 7 | 노트북 §정리가 *"실행 결과를 보고 채워 넣을 자리"* 인 **템플릿 상태**인데 이미 결론으로 인용됨 | 근거 |

4번이 결정적이다. **지금은 "구조가 없다"와 "방법이 구조를 못 본다"를 구분할 수 없다.**

## 2. 목표와 성공 기준

1. 이 데이터가 실제로 몇 덩어리로 나뉘는가 — **널 베이스라인과 비교해서**
2. 그 덩어리가 돌봄부담과 어떤 관계인가

**성공 기준은 "군집이 잘 나오는 것"이 아니다.** 어느 쪽이 나와도 결론이 서는 것이 성공이다.

| 결과 | 결론 | 다음 |
|---|---|---|
| 실루엣이 널 분포보다 뚜렷이 높다 | 구조가 있다 | 군집 라벨 기반 새 모델 학습 검토 |
| 널 분포와 겹친다 | 구조가 없다 확정 | §7-3 이 비로소 근거를 갖는다 |

**어느 쪽이든 발표에 쓸 수 있는 결론이 나온다.** 이것이 이 실험을 하는 이유다.

## 5. 파이프라인

| 단계 | 내용 | 검증 게이트 |
|---|---|---|
| **S1 조인** | 38변수 + target 값 튜플로 `2024.csv` ↔ `cb_dataset_v1` 조인해 각 raw 행에 `split`·`cv_fold` 부여. 변수↔원문항 대응은 `docs/학습데이터셋-컬럼정의.md` 의 **원 문항** 열 사용 | **3,000/3,000 유일 매칭이 아니면 중단**하고 설계 재검토 |
| **S2 정리** | 버림(**합집합** — 아래 집합은 서로 겹친다): 전부결측 42 · 상수 33 · 식별자 `ID` `ADDCODE` · 조사 가중치 `WT` · target `I13` · 주관식 텍스트 45 · **응답자 100명 미만 블록** | 제외 사유별 컬럼 목록과 **최종 남은 컬럼 수**를 표로 기록 |
| **S3 게이트** | 결측 패턴이 동일한 컬럼을 묶어 **게이트 이진 변수** 생성 (~20개). "이 사람이 이 블록에 응답할 자격이 있었나" | 게이트별 응답자 수 기록. 게이트끼리 완전 중복이면 하나로 합침 |
| **S4 척도 판정** | 남은 컬럼을 binary / nominal / ordinal / continuous 로 분류. 코드북을 못 읽으므로 **고유값 수·값 범위·컬럼명 규칙**으로 1차 판정하고 사람이 검토 | 판정표를 문서에 남긴다. 애매한 것은 nominal 로(보수적) |
| **S5 거리** | **Gower 직접 구현**(numpy ~30줄, 설치 불필요). binary·nominal은 일치/불일치, ordinal은 정규화 랭크차, continuous는 범위로 나눈 절대차. 결측 쌍은 pairwise 제외. **블록 가중치 정규화** — 게이트에 딸린 문항 수로 나눠 블록당 기여를 동등하게 | 대칭성·대각 0·값역 [0,1] 검사 |
| **S6 군집** | PAM(k-medoids)과 계층군집(average linkage) 둘 다. k = 2~10. seed 고정 | 두 방법의 결과가 크게 다르면 그 사실을 보고 |

**train 2,398건만 사용한다. test 602건은 열지 않는다.** 군집화는 비지도지만 결과가 모델
학습으로 이어질 수 있으므로 기존 규율(`CLAUDE.md`)을 그대로 지킨다.

## 6. 검증

기존 실험에 없던 부분이다. **이것이 이번 실험의 본체다.**

| 검사 | 방법 | 판정 |
|---|---|---|
| **널 베이스라인** | 각 열을 독립적으로 셔플해 변수 간 관계만 없앤 뒤 **동일 파이프라인**을 태운다. 20회 반복해 실루엣 분포를 만든다 | 실측 실루엣이 널 분포의 상위 5% 밖이면 "구조 있음" |
| **게이트 오염도** | 군집 라벨과 게이트 벡터의 상호정보량 | 높으면 "분기 군집"이라고 정직하게 보고한다 |
| **부담과의 관계** | ARI · NMI **에 더해** 교차표와 **군집별 고부담 리프트** | ARI 하나로 "무관"이라 단정하지 않는다 |
| **누수 비교** | 누수 6변수 **포함 / 제외** 두 벌을 같은 방법으로. 원본에서의 식별은 `docs/학습데이터셋-컬럼정의.md` 의 원 문항 코드로 한다 (`caregiver_life_satisfaction` = **I14** 외 5개) | 군집이 I14 로 갈렸는지 확인. 모델 학습 진행 여부는 이 결과를 보고 함께 결정 |

## 10. 일정 (2026-09-04 까지)

| | 내용 |
|---|---|
| **1일차** | S1~S6 + 널 베이스라인 → **A안** 결과. 누수 포함/제외 두 벌 |
| **2일차** | A 결과를 보고 **B안**(하위 문항까지 Gower) 또는 **C안**(2층 군집화) 중 선택 |

**A안의 입력을 정확히 적으면** — 결측 0 인 173개에서 `ID`·`ADDCODE`·`WT`·`I13`·상수 컬럼을
뺀 나머지에, S3 에서 만든 게이트 이진 변수 ~20개를 더한 것이다. 게이트는 나머지 314개 컬럼의
**"존재 여부"를 압축한 변수**이므로, 내용은 쓰지 않아도 507컬럼의 구조 정보는 모두 반영된다.

A안은 입력 전체가 결측 0 이라 거리 계산에 논란의 여지가 없고 그 자체로 완결된다.
B·C 는 A 결과의 게이트 오염도를 보고 정한다.
