# 기기 대조표 — 어느 노트북이 누구인가

팀원 4명이 각자 노트북으로 같은 저장소에서 작업한다. 세션마다 사용자가 다르므로
**기기 ID ↔ 팀원** 대응을 여기 모아 둔다. 세션이 시작되면 훅이 자동으로 기기를 식별한다.

## 무엇을 적고 무엇을 안 적나

| 적는 것 | 안 적는 것 |
|---|---|
| 기기 ID = `sha256(MAC)` 앞 8자 | **원본 MAC 주소** — 기기 고유 식별자라 공개 저장소에 남기지 않는다 |
| 기기 이름 (`scutil --get ComputerName`) | IP·사용자 계정·시리얼 번호 |

헌법 원칙 III(식별 정보 미보관)의 직접 대상은 서비스 이용자 데이터지만, 같은 취지를 개발
기록에도 적용한다. 재현 공식은 아래 한 줄이며, 필요하면 누구든 자기 기기에서 대조할 수 있다.

```bash
bash scripts/JSG-machine-id.sh          # 내 기기 ID 확인
ifconfig en0 | awk '/ether/{print $2}' | tr -d '\n' | shasum -a 256 | cut -c1-8
```

같은 기기·같은 폴더이므로 **MAC 도 기기 ID 도 똑같다.** 따라서 기기 ID 는
"어느 장비인가"까지만 답한다. 세션을 가르는 것은 `session_id` 앞 8자이고,
**사람을 가르는 것은 그 세션에서 본인이 밝힌 이름뿐이다.**

| 구분하려는 것 | 쓸 수 있는 것 |
|---|---|
| 어느 장비인가 | 기기 ID (`sha256(MAC)` 앞 8자) |
| 어느 세션인가 | `session_id` 앞 8자 — 훅이 세션 시작 때 알려 준다 |
| **누구인가** | **세션에서 밝힌 이름.** 밝히기 전에는 단정하지 않는다 |

### 같은 파일을 동시에 고치는 문제

여러 세션이 한 폴더를 공유하므로 **작업기록 파일을 덮어쓰지 말고 이어 붙인다.**
실제로 09:38 에 다른 세션이 `오현근.md` 에 2일차 절을 쓰는 중이었다.
팀원별로 파일이 나뉘어 있는 현재 구조가 충돌을 줄여 준다.

## 세션별 작성자 장부 — 실제로 사람을 가르는 것

계정 `pioneer3` 를 팀이 공유하므로 **기억 저장소(`~/.claude/.../memory/`)까지 공유된다.**
거기에 "이 노트북 사용자는 X" 라고 적으면 다른 세션이 덮어써서 다음 사람을 오인한다
(2026-09-02 실제로 발생했다). 그래서 이름은 **`session_id` 로 칸이 나뉜 장부**에 적는다.

```bash
bash scripts/JSG-session-author.sh set 조성기   # 이 세션 작성자 기록
bash scripts/JSG-session-author.sh get          # 이 세션 작성자 확인
bash scripts/JSG-session-author.sh list         # 전체 장부
```

- 장부: `.claude/session-authors.local.json` — 세션 id 앞 8자가 열쇠라 세션끼리 덮어쓰지 않는다.
  기기 로컬 파일이므로 `.gitignore` 로 제외한다.
- 세션 시작 훅이 장부를 조회한다. **이름이 없으면 "작성자 미확정 — 먼저 물어라"** 를 주입하므로
  추측으로 귀속하는 일이 생기지 않는다.

## git 작성자 — 커밋마다 지정한다

**`git config --local user.name` 은 바꾸지 않는다.** 이 작업 폴더는 `.git/config` 가 하나뿐인데
여러 세션이 동시에 쓴다(위 §한계 참조). `--local` 로 이름을 걸면 **다른 팀원 세션의 커밋까지
그 이름으로 찍힌다.** 현재 값 `pioneer3` / `vrmaker65@gmail.com` 은 그대로 둔다.

작성자는 커밋 단위로 지정한다. 이름은 세션 장부에서 가져온다.

```bash
git -c user.name="$(bash scripts/JSG-session-author.sh get)" commit -m "..."
```

이메일은 기존 값을 그대로 쓰므로 `-c user.email` 은 붙이지 않는다 — 사용자가 따로 지정할 때만
붙인다. 팀원별로 클론이나 워크트리를 나누게 되면 그때는 각 폴더에서 `--local` 을 걸어도 된다.

> **2026-09-02 11:26 개정 (신지현)** — 이전 판은 각자 `git config --local` 을 걸라고 권했다.
> 그러나 클론이 공유되는 현재 구조에서는 그것이 오히려 오귀속을 만든다. 09:48 에 정해진
> "커밋마다 `git -c`" 방침에 맞춰 고쳤다.
