### 7-3. 시각화 — 요청과 판단

차트 후보를 추천받아 **A~G 전부와 대전 지역 지도**를 채택했다.

| 차트 | 내용 |
|---|---|
| A | 부담 분포 100% 누적 막대 — 고부담 54.3% 를 한눈에 |
| B | **k별 혼동행렬** (2×2 + 5×5) — 문항 선정 기준의 근거 |
| C | 문항 수별 성능 곡선 (k=38→6) |
| D | 설명력 순위 + 배제 변수 강조 |
| E | 군집화 — 소형 다중 패널 + 실루엣 |
| F | 7문항 vs 14문항 지표 4종 |
| G | 연령–서비스 사각지대 다이어그램 |
| H | **대전광역시 기관 34곳 지도** (OSM 타일) |

**본인이 판단한 것**

- **혼동행렬을 문항 선정 근거로 쓸 수 있는지 물었다.** 직접적인 기준은 아니지만
  "기준이 옳았는지"의 증거가 된다는 답을 받고 채택했다. 실제로 계산해 보니
  **k=6 에서 최고부담군 재현율이 0.183 → 0.054 로 무너지는 것**이 드러나,
  "F1 이 떨어져서"보다 훨씬 설득력 있는 정지 근거가 나왔다.
- **부담 분포를 누적 막대로 바꾸라**고 지시 — 표로는 54.3% 가 글로만 전달됐다.
- **대전 지역 지도**를 요청 — 전국 커버리지 지도는 96.5% 라 차이가 안 보인다는 판단을 받아들이고
  현재 위치인 대전으로 좁혔다.
- **색 구분이 안 된다고 지적하고 가독성 우선을 지시했다.** "브랜드 톤을 맞춘 것은 좋지만
  그래프에서 구분이 힘들면 의미가 없다"는 기준을 제시했다.
- **11페이지 여백을 지적**하고 그래프와 표를 균형 있게 배치하도록 지시했다.
