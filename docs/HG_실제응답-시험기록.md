## 3. 실제 사례

### 잘 맞힌 경우

```
실제 고부담군 → 예측 고부담군   확신 0.577

  일과 만족 보통 · 가족 지지 보통 · 도움 시간 하루 12시간 이상 ·
  가구주 아버지 · 퇴사 이유 해당없음 · 응답자 어머니 ·
  일의 의미 이해 전혀 이해하지 못한다

  근거: 도움 시간 +0.47 · 일과 만족 +0.26 · 가족 지지 +0.23
```

**하루 12시간 이상 돌봄**이 가장 크게 작용했습니다. 상식과 맞습니다.

### 한 칸 빗나간 경우

```
실제 최고부담군 → 예측 고부담군   확신 0.419

  일과 만족 보통 · 가족 지지 매우 지지함 · 도움 시간 하루 몇 시간 정도 ·
  가구주 아버지 · 응답자 어머니 · 일의 의미 이해 어느 정도 이해한다
```

**가족 지지가 매우 좋고 도움 시간도 길지 않은데 실제로는 최고부담**이었습니다.
문항이 담지 못한 사정이 있었을 것입니다.

### 놓친 고부담 — 실제 고부담인데 아니라고 본 경우

이 서비스에서 가장 비싼 오류입니다. 72명이 여기 해당합니다.

```
실제 고부담군 → 예측 중간부담군   확신 0.458

  일과 만족 좋아하는 편 · 가족 지지 매우 지지함 · 도움 시간 도움이 필요하지 않음 ·
  가구주 아버지 · 응답자 아버지 · 일의 의미 이해 어느 정도 이해한다
```

```
실제 고부담군 → 예측 중간부담군   확신 0.610

  일과 만족 좋아하는 편 · 가족 지지 지지하는 편 · 도움 시간 도움이 필요하지 않음 ·
  퇴사 이유 출퇴근 거리 · 응답자 아버지 · 일의 의미 이해 어느 정도 이해한다
```

**놓친 사례에 공통점이 보입니다** — 셋 다 **"도움이 필요하지 않음"** 이라고 답했습니다.
당사자가 손이 많이 가지 않는데도 보호자는 부담이 컸던 경우입니다.

돌봄 부담이 **돌봄 시간만으로 정해지지 않는다**는 뜻이고, 7문항이 그 부분을 못 담고 있습니다.

### 과잉 경고 — 실제로는 아닌데 고부담이라 본 경우

```
실제 중간부담군 → 예측 고부담군   확신 0.566

  일과 만족 보통 · 가족 지지 지지하는 편 · 도움 시간 하루 12시간 이상 ·
  응답자 어머니 · 일의 의미 이해 전혀 이해하지 못한다

  근거: 도움 시간 +0.47 · 일과 만족 +0.26 · 일의 의미 이해 +0.22
```

**12시간 이상 돌보지만 본인은 중간이라고 답한 분**입니다. 모델은 시간을 크게 보는데
실제 부담감은 사람마다 다릅니다.

**이 방향의 오류는 상대적으로 안전합니다.** 부담이 크지 않은 분에게 기관을 안내하는 것은
놓치는 것보다 낫습니다. 결정 가중치로 이 방향을 일부러 키운 이유이기도 합니다.

### 판정 불가로 뺀 15건

```
실제 고부담군 → 판정 불가(희소)   확신 0.783  희소성 -2.648

  일과 만족 싫어하는 편 · 가족 지지 전혀 지지하지 않음 · 도움 시간 12시간 이상 ·
  가구주 배우자 · 퇴사 이유 사업체 휴·폐업 · 응답자 배우자 ·
  일의 의미 이해 전혀 이해하지 못한다
```

**확신도가 0.783 로 매우 높은데도 판정하지 않았습니다.** 배우자가 배우자를 돌보는
드문 조합이라 희소성에 걸렸기 때문입니다.

```
실제 최고부담군 → 판정 불가(확신 부족)   확신 0.281

  일과 만족 매우 좋아한다 · 가족 지지 매우 지지함 · 도움 시간 도움이 필요하지 않음 ·
  응답자 어머니 · 일의 의미 이해 거의 이해하지 못한다
```

**답변만 보면 부담이 적어 보이는데 실제로는 최고부담**이었습니다. 모델도 확신하지 못해
0.281 로 갈피를 못 잡았고, 그래서 판정하지 않았습니다. **제 역할을 한 것입니다.**

### 판정 불가 15명의 실제 부담 수준

| 실제 | 인원 |
|---|---|
| 최고부담 | 4명 |
| 고부담 | 4명 |
| 중간 | 4명 |
| 저부담 | 2명 |
| 없음 | 1명 |

**골고루 흩어져 있습니다.** 특정 구간에 몰리지 않으니, 판정 불가가 어느 한쪽을 체계적으로
빠뜨리는 것은 아닙니다. **여덟 명이 실제 고부담**이었고, 그래서 이들에게도 기관 안내가
나가는 설계(FR-021j)가 중요합니다.

```
이유: 희소 8건 · 확신 부족 7건
```

## 4. 확신도가 높을수록 실제로 더 맞는가

| 확신도 | 건수 | 정확도 |
|---|---|---|
| 0.3 ~ 0.4 | 80 | 43.8% |
| 0.4 ~ 0.5 | 272 | 45.6% |
| 0.5 ~ 0.6 | 191 | 52.9% |
| 0.6 ~ 0.7 | 38 | 57.9% |
| 0.7 이상 | 6 | 66.7% |

**확신도가 올라가면 정확도도 따라 올라갑니다.** 모델이 "잘 모르겠다"고 말할 때는 실제로도
잘 모르는 것이고, "확실하다"고 할 때는 실제로 더 맞습니다.

판정 불가 임계값(0.324)이 왜 저기인지도 이 표가 설명합니다. 그 아래는 정확도가 더 떨어집니다.

## 5. 정리

| # | 발견 | 뜻 |
|---|---|---|
| 1 | 공식 평가 수치와 정확히 일치 | 배포된 서비스가 평가 때와 같은 답을 낸다 |
| 2 | 열에 아홉이 맞거나 옆 칸 | 정반대로 틀리는 일은 드물다 |
| 3 | **놓친 고부담은 "도움 필요 없음"에 몰림** | 돌봄 시간만으로 부담이 정해지지 않는다. 7문항의 한계 |
| 4 | 과잉 경고는 "12시간 이상"에 몰림 | 모델이 시간을 크게 본다. 안전한 방향의 오류 |
| 5 | 확신도 ↑ → 정확도 ↑ | 모델의 자신감이 믿을 만하다 |
| 6 | 판정 불가 15명이 구간에 골고루 | 어느 한쪽을 체계적으로 빠뜨리지 않는다 |
| 7 | 판정 불가 중 8명이 실제 고부담 | **기관 안내를 함께 내보내는 설계가 중요하다** |
