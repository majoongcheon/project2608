# 1부. 이 서비스는 "식당"이에요 🍳

우리가 만든 건 **부담이 얼마나 무거운지 재 주고, 갈 곳을 알려주는 식당**이에요.

손님이 오면 → 주문을 받고 → 주방에서 만들어서 → 다시 손님한테 가져다줘요.

```
                        🙋  손님 (보호자)
                         │
                         │  질문 7개에 답해요
                         ▼
        ┌────────────────────────────────┐
        │  🍽️  메뉴판 주는 사람 (화면)      │   :9503
        │      Vue + 지도(Leaflet)         │
        └────────────────────────────────┘
                         │  "이 손님 답이에요!"
                         ▼
        ┌────────────────────────────────┐        ┌──────────────────┐
        │  🍳  주방 (백엔드)                │◀──────▶│ 📦 창고 (MariaDB) │
        │      Node.js + Express           │  :9523 │  기관 1,283곳     │
        └────────────────────────────────┘        └──────────────────┘
                         │
                         │  🚪 아주 작은 창구로만 얘기해요
                         │     (유닉스 소켓 = 밖으로 난 문이 없어요)
                         ▼
        ┌────────────────────────────────┐
        │  👩‍🍳  점수 매기는 요리사 (파이썬)   │
        │      배운 것이 담긴 상자 models/  │
        └────────────────────────────────┘
```

**여기서 제일 재밌는 부분!** 🤫

주방(백엔드)은 **점수를 매길 줄 몰라요.** 진짜로요! 계산하는 방법을 아예 안 배웠어요.

그래서 요리사(파이썬)를 잠깐 재우면, 주방은 이렇게 말해요 — **"저는 모르겠어요."**
그리고 요리사를 깨우면 다시 답이 나와요. 다섯 번이나 해 봤는데 매번 똑같았대요.

그리고 요리사한테 가는 창구는 **밖에서 안 보여요.** 창문이 아니라 벽에 뚫린 작은
구멍이라서, 밖에 있는 사람은 거기 뭐가 있는지도 몰라요. 🔒

# 2부. 요리사는 어떻게 점수를 매길까? 🍬

손님이 답한 **7개**를 받아서, **일곱 걸음**을 걸어요.

```
   답 7개  [4, 4, 5, 1, 없음, 3, 1]
      │
  1️⃣  빈칸 표시하기      안 고른 건 "없음" 도장을 꽝! (−1)
      │
  2️⃣  스티커 붙이기      칸 53개짜리 판에, 고른 칸에만 스티커 ⭐
      │
  3️⃣  사탕 나눠 담기      주머니 5개에 사탕 100개를 나눠요
      │                  [1.9 · 20.8 · 42.9 · 28.8 · 5.6개]
      │
  4️⃣  "이런 답 본 적 있어?"  전에 본 적 없는 이상한 답이면 손을 들어요 🙋
      │
  5️⃣  잘 모르겠으면 말 안 해요   ← 여기가 제일 중요해요!
      │
  6️⃣  제일 뚱뚱한 주머니 고르기   앞의 두 주머니는 살짝 크게 봐요 (1.1배)
      │
  7️⃣  "왜 그렇게 봤는지" 3개 말하기
      │
      ▼
   "중간부담군이에요" + 이유 3개 + 가까운 기관
```

### 조금만 더 설명할게요

**3️⃣ 사탕 나눠 담기** — 스티커 붙은 칸마다 점수가 정해져 있어요. 그걸 다 더하면
주머니 5개에 사탕이 나뉘어요. 사탕이 제일 많은 주머니가 답이에요.

**5️⃣ 모르겠으면 말 안 해요** — 이게 진짜 착한 부분이에요. 🌟

요리사는 두 번 스스로한테 물어봐요.

- *"내가 확실해?"* → 제일 뚱뚱한 주머니에도 사탕이 별로 없으면 → 안 말해요
- *"이런 답 본 적 있어?"* → 처음 보는 답이면 → 안 말해요

그럼 **"잘 모르겠어요"** 라고 솔직하게 말해요. 100명 중에 2~3명한테 그래요.

**그런데!** 모르겠다고 해도 **가까운 기관은 꼭 알려줘요.** 🏥
왜냐면 모르겠는 사람이 제일 힘든 사람일 수도 있으니까요. 실제로 "모르겠어요" 한
15명 중에 **8명이 진짜 힘든 분**이었어요.

**6️⃣ 1.1배가 뭐예요?** — 힘든 분을 놓치면 안 되니까, 앞의 두 주머니(제일 힘든 쪽)를
**일부러 조금 크게** 봐요. 손을 더 크게 벌리는 거예요. 그래서 100명 중 77명을 찾아내요.

---

## 그래서 뭐가 좋은데요? 🎈

이 서비스는 **똑똑한 척을 안 해요.**

- 모르면 **모른다고 말해요**
- 그래도 **갈 곳은 알려줘요**
- 왜 그렇게 봤는지 **이유를 보여줘요**

100점짜리 점쟁이가 아니라, **"혼자 힘들어하지 마세요" 하고 말을 거는 친구**예요.
