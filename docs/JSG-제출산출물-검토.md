## 3. 발견 — `policy.json` 이 하나 더 필요합니다 ★

**`predict.py` 는 파일 셋을 읽습니다.**

```
model.joblib    가중치와 전처리
schema.json     입력 검증
policy.json     결정 가중치 · 판정 불가 임계값 · 빈도표 · 기여도 기준
```

**요구 6종만 복사하면 `predict.py` 가 실행되지 않습니다.** 실제로 확인했습니다.

| 폴더 구성 | `predict()` 호출 |
|---|---|
| 요구 6종만 | **`FileNotFoundError: policy.json`** |
| 6종 + `policy.json` | **성공** — 구간 3 · 최대확률 0.4295 |

그래서 **`final/` 에는 7개를 넣었습니다.** 오현근이 기록에 적어 둔 이유가 이것입니다 —

> *"Pipeline 이 임계값·빈도표·가중치를 담지 못하는데, `predict.py` 에 숫자를 박으면
> 모델을 바꿀 때 조용히 갈리기 때문이다."*

제출 규정이 **정확히 6개**를 요구한다면, `policy.json` 을 빼는 대신 그 값들을
`predict.py` 안에 넣어야 합니다. **권하지 않습니다** — 모델을 바꿀 때 어긋나기 쉽습니다.
